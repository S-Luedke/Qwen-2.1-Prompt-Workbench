# Privacy

This page collects nothing, stores nothing on any server, and contacts no third party.

## No external requests

Everything the page needs is contained in the single `index.html` file. The typefaces are
embedded in it as base64. There is **no** request to Google Fonts, no CDN, no analytics, no
tracking pixel, no advertising, no embedded video and no social widget. Opening the page
produces exactly one request: the page itself, served by GitHub Pages.

## No cookies, no tracking

The page sets no cookies and needs no consent banner, because there is nothing to consent to.

## What you type

Text entered into the template fields is kept in your own browser's `localStorage` so your
edits survive a reload. It never leaves your device. It is not transmitted, not readable by
the page owner, and not shared with other visitors. Clearing your browser's site data for this
domain removes it.

## GitHub Pages

The site is hosted on GitHub Pages. As with any web server, GitHub processes connection data
such as your IP address to deliver the page. That processing is GitHub's, described in the
[GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).
The page owner has no access to it and receives no logs.
